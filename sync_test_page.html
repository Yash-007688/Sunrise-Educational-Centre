  • chat_message → new_chat_message

  • submit_doubt → update_doubts

Database Tables:

  • live_class_messages - Chat messages
  • polls - Poll questions
  • poll_options - Poll answer options
  • poll_votes - User votes
  • doubts - Student doubts
