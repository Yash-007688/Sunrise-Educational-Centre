## Video Format Recommendations
- **Format**: MP4 (recommended) or WebM
- **Codec**: H.264 for MP4
- **Resolution**: 1280x720 (720p) or 1920x1080 (1080p)
- **Aspect Ratio**: 16:9 (widescreen)
- **File Size**: Keep videos under 50MB each for faster loading

## How to Add Videos
1. Upload your video files to this directory
2. Name them exactly as listed above (use lowercase with hyphens)
3. Ensure the file extension is `.mp4` or `.webm`
4. Videos will automatically appear on the homepage in the "What Our Students Say" section

## Notes
- The videos will have player controls (play, pause, volume, fullscreen)
- Videos are set to load metadata only initially (faster page load)
- If a video file is missing, the video player will show an error message
